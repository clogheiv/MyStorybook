# My Storybook — Agent Guidelines

## Purpose
This repository is for building the My Storybook app in a clean, incremental, reviewable way.

## Rules
- Never push directly to main.
- Work only on feature branches.
- Keep changes small and reviewable.
- Do not modify unrelated files.
- Prioritize stability and clarity.

## Development Principles
- Calm, readable code over clever code.
- Incremental progress.
- Clear commit messages.
- Respect existing project structure.

## Safety
- Do not introduce breaking changes without explanation.
- Confirm before adding new dependencies.
- Maintain build stability at all times.

## Product Direction
Focus on:
- Personalization
- Calm reading experience
- Narration support
- Offline capability
- Privacy-first design

Stories are better together.
